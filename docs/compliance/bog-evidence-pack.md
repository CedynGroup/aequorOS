# aequorOS evidence pack for the Bank of Ghana application

Prepared 8 October 2026 for the pilot bank's risk and procurement teams, as
requested in [#356](https://github.com/CedynGroup/aequorOS/issues/356).
Delivery status reviewed 30 October 2026 (UTC) against repository version
`3cd14f4d99353c75c1e773b9eb78a91bc804e9e9`.

The public pages describe the product end state. This regulator-facing pack
records present implementation status and the work needed to deliver those
outcomes. It is not an approval, a certification or a signed assurance.

- **Delivered** means the specific, bounded code capability or historical result
  in that row has supporting evidence. It does not establish deployment,
  configuration, contractual commitments or regulatory approval.
- **In progress** means part of the outcome exists, but the linked acceptance
  criteria are not yet satisfied in full. It is not a claim that every remaining
  item is currently staffed or scheduled.
- **Planned** means the outcome has no completed implementation or verification
  in this evidence record. An open issue is a delivery obligation, not proof.

The public-outcome table and delivery tracker below govern present status. The
technical inventory in sections 2–9 preserves the earlier, dated code evidence;
its Delivered rows describe only the narrow facts stated there.

The historical inventory cites its source by file and line number in the aequorOS code
repository, written as `file:line`, at code version
`7c3fecf2a61a45adff04bc9f823d974ee11e00c6`. Controls added since that version
are described in the [transport security contract](../../backend/docs/transport_security.md),
the [bank encryption contract](../../backend/docs/bank_encryption.md),
the [field encryption contract](../../backend/docs/bank_field_encryption.md) and the
[tamper-evident records contract](../../backend/docs/tamper_evident_records.md).

## 1. Application documents and responsibility

This pack supplies aequorOS's technical input to the bank's application. The BoG
[Outsourcing Directive, November 2024](https://www.bog.gov.gh/wp-content/uploads/2024/11/BOG-Outsourcing-Directive.pdf),
paragraph 87 and Annexure V, requires application evidence and a register of
outsourced services. The bank's own risk assessment, due diligence, risk
framework, register and contract remain with the bank risk team.
