# AQS evidence pack for the Bank of Ghana application

Prepared 8 October 2026 for the pilot bank's risk and procurement teams.
This is the repository-backed draft requested by [#356](https://github.com/CedynGroup/aequorOS/issues/356).
It is not an approval, certification or signed assurance.
This pack is complete for everything the codebase evidences; the To confirm
items are operator facts to be answered by AQS before submission, and legal
wording is left to counsel.

“Built” means an implementation is present in the cited source. “Planned” means
the control is not established today. Code defaults and deployment comments do
not establish the active production settings. No production system was queried
for this pack. Sources use repository-relative `file:line` references; attach
the reviewed commit and dated deployment evidence to the bank's final copy.
Implementation baseline reviewed: `7c3fecf2a61a45adff04bc9f823d974ee11e00c6`.

### 3.1 Outbound service boundaries

- **AI routing:** Anthropic uses its SDK with an explicit API key, timeout and
  retry budget (`backend/app/services/ai/client.py:319`). OpenAI uses
  `https://api.openai.com/v1` and the `/responses` path
  (`backend/app/services/ai/openai_model.py:70`). Google requires a configured
  `GEMINI_API_URL` (`backend/app/services/ai/google_model.py:111`, `:172`).
  Endpoint hostnames and SDK defaults do not establish processing countries;
  Q08 must identify every enabled vendor and any failover destination.
- **Signing custody:** the OpenBao signing client submits a base64-encoded
  SHA-256 digest, key reference and algorithm settings to Transit, with TLS
  certificate verification enabled by default or a configured CA bundle
  (`backend/app/services/attestation/openbao.py:246`, `:566`). The committed
  vault container listener is plaintext behind its same-host proxy
  (`deploy/openbao/docker-compose.openbao.yml:84`). Q02/Q12/Q13 must establish
  the actual host, custody permissions and both sides of that proxy boundary.
- **Staff support:** the browser calls the console’s same-origin `/api/op`
  proxy, which forwards the session bearer and request body to
  `OPERATOR_API_URL`; authorization remains with the operator API
  (`console/app/api/op/[...path]/route.ts:24`, `:38`, `:55`;
  `console/.env.example:7`). Q07/Q10 must include this path’s network controls
  and what staff can read or change.
- **Public enquiries/analytics:** when configured, contact-form data goes to
  Resend and the configured recipient, while an enabled analytics beacon
  contacts Cloudflare (`frontend/app/api/contact/route.ts:78`, `:114`;
  `frontend/components/Analytics.tsx:27`). Q04/Q05/Q07 must establish active
  use, processing locations and applicable retention; this is separate from
  bank financial ingestion.
