## 1. What the template is, and how it is bound

The extractor therefore captured NO input cells on Sheets 1–7 and only the row ordinals `A8:A17` (1–10) on Sheet 8. **Sources — one resolver, `bsd11.register` (`sources_ext/bsd11.py`).** The bound **column key IS the field**; the params name the register and the rank:

| Params | Register / population | Fields returned (by column key) | Fields returned as `None` → cell stays input_required |
|---|---|---|---|
| `{"register": "directors", "rank": N}` | N-th **director**: active `related_parties` individuals holding role `director` or `board_chairman` (`related_party_roles`), ordered by earliest director appointment (unknown last), then name — the same order on Sheet-2 and Sheet-4 | `name` (full name + `contact.address` when present) · `appointed` (ISO date) · `shares` (Σ `shareholdings` as "1,000,000 (2.50%)"; "Nil" when the register records no `shareholder` role; `None` when the shareholder role exists but no holding rows do) · `balance` (Σ cedi balances of the director's LOAN facilities) · `rate` (the contractual rate ×100 when the director has exactly ONE facility) · `facility_type` (distinct product names) · `security` (distinct `crm_collateral_class` attributes) | `employment` (full/part time), `interests` (in other companies), `secured`/`unsecured`/`guaranteed` split, `approved` (board approval date), rank beyond the register |
| `{"register": "officers", "rank": N}` | N-th **officer**: individuals with a key-management role (`chief_executive_officer`, `chief_finance_officer`, `chief_risk_officer`, `chief_compliance_officer`, `head_internal_audit`, `other_key_management`, `board_secretary`) who are NOT directors (a director-CEO is reported once, as a director) | as above | as above |
| `{"register": "summary", "group": "directors"|"officers"}` | Sheet-1 aggregate over the whole group | `current` = Σ LOAN balances of every party in the group | `previous`, `granted`, `repaid`, `written_off` (half-year movements) |
| `{"register": "large_exposures", "rank": N}` | N-th largest **customer**: canonical positions grouped by counterparty (or by `group_reference` = connected group), on-balance `LOAN`/`INTERBANK_PLACEMENT`/`SECURITY_HOLDING` + off-balance `LC_GUARANTEE`/`COMMITMENT_UNDRAWN`, sovereign / central-bank / government counterparties and counterparty-less positions excluded, ranked by total desc then name | `name` · `on_balance` · `off_balance` · `total` (= on + off) · `security` (Σ `crm_collateral_ghs` + `crm_guarantee_ghs` when any facility carries them) · `pct_total` (= total ÷ net worth × 100) · `pct_secured` (= min(total, security) ÷ net worth × 100) · `pct_unsecured` (= (total − secured) ÷ net worth × 100) | `security`/`pct_secured`/`pct_unsecured` when no facility carries a security attribute; every percentage when BSD2 `D135` is unavailable or ≤ 0; rank beyond the population |

**Linking a canonical counterparty to a register party** uses the SAME documented rule as the Large-Exposures return (`le_generation._funding_entities`): a **normalised-name match** (`" ".join(name.lower().split())`) against `related_parties.full_name` — nothing else is inferred. Cedi amounts follow the platform's convention (`balance_ghs`/`notional_ghs` attribute wins; base-currency book raw; foreign-currency book WITHOUT an ingested conversion contributes zero, never an invented rate); snapshots are the current generation, latest on/before the period end, `accepted`/`warning` only.

## 2. Guide rules applied and documented decisions

| Guide / Act item | Rule | How the map applies it |
|---|---|---|
| Guide BSD11 ¶ "Advances to Directors" | details of advances granted to each Director (including Chairman and Managing Directors) on sheet 4 | director = related-party roles `director` / `board_chairman`; a Managing Director who is also a board member holds both roles and appears once, as a director |
| Guide BSD11 ¶ "Advances to Officers and other Employees" | total number of employees who have borrowed and total outstanding may be indicated | Sheet-1 row 14 current balance from key-management parties' facilities; **Sheet-5 (numbers × amounts by employee category) needs a staff-loan register — input_required** |
| Guide BSD11 ¶ "relatives" | exposures to spouse(s), sons, daughters, step-children, siblings, parents | the related-party register has no relative role → **Sheet 8 input_required** ("relatives register required") |
| s.47 "net worth" | advances, credits and guarantees as a percentage of net worth | **net worth := BSD2 line 16 Shareholders' Funds (`D135`)** — paid-up capital + reserves on BoG's own balance-sheet return of the same reporting date, computed first as a declared dependency. Documented choice: Act 673 speaks of "net worth" (not the LE regime's Net Own Funds / Tier 1 proxy); if BoG specifies an adjusted net worth this is a one-constant change (`NET_WORTH_CELL`). Percentages are exposure ÷ net worth × 100 exactly as the sheet header states — the sheet has no template formula, so the relationship is the resolver's and is proved by the test. |
| s.47 exposure | "advances, credits and guarantees" | on-balance credit types = the platform's LE definition; off-balance = LC/guarantees + undrawn commitments; sovereign/BoG/GoG excluded on the LE return's documented basis |
| Half-year movements (Sheet-1 B–E) | previous balance / granted / repaid / written off | the platform's reporting periods are **monthly**; a BSD11 package is struck on a monthly period, so "period start − 1 day" would be the prior month-end, not the prior half-year end. Movements are therefore **input_required** — never derived from the wrong opening date. |
| Total rows without formulas (Sheet-3 row 15, Sheet-5 row 22) | the official file has no formula in these total rows | bound as `input_required` ("official TOTAL row carries no template formula — bank totals its rows"); a `Σ rows above` would be a line the template does not carry |
| Ordinals (Sheet 8 A8:A17) | template row numbers captured as numeric inputs | kept as `constant` 1–10 (`unscaled`) so the export reproduces the official column |

## 4. Residual unmapped lines — data the bank must supply

- **Sheet-1 rows 12–15, columns B–E** (previous balance, granted, repaid, written off): half-year facility movements — the platform holds monthly snapshots, not a facility ledger.
- **Sheet-1 row 12 / Sheet-3 (all)**: facilities to **firms in which directors are interested** — the related-party register records parties and roles, not a director's interests in other companies; a director-interest register is required (particulars, secured/unsecured amounts, nature of security, type, present balance, date granted; TOTAL row).
- **Sheet-1 row 15 / Sheet-5 (all)**: advances to **other employees / officials by category** — a staff-loan register (housing / vehicle / other secured / unsecured: number and amount per category, and the C. total).
- **Sheet-2 columns D and F** (full/part-time; interests held in other companies) — not fields of the register.
- **Sheet-4 columns C, D, E, I** (secured / unsecured / guaranteed split; date approved by the board) and column G when a director has several facilities — the facility's security/approval record.
- **Sheet-6 columns F, G, H** when no facility of the customer carries the documented `crm_collateral_ghs` / `crm_guarantee_ghs` attribute (absence is not zero); every percentage while BSD2 `D135` is unavailable.
- **Sheet-7 (all)**: immovable property accepted in satisfaction of debt — no canonical entity.
- **Sheet 8 columns B–I**: exposures to relatives of directors / significant shareholders — the register has no relative role.
- Any director / officer / customer row beyond the register or population (rank exhausted) stays blank + input_required (see §7 ask 3).

## 6. Cross-form dependencies

- **BSD2** (`depends_on`): Sheet-6 net worth = computed BSD2 `D135` (16. Shareholders' Funds = 14 paid-up capital + 15 reserves) of the same reporting date, in base units. If BSD2's capital lines are themselves input_required, `D135` evaluates to 0 and every Sheet-6 percentage stays blank (input_required) — nothing is divided by an empty net worth.
- **BSD7A** (`depends_on`, catalogue): no BSD11 cell reads it.
- Consistency with **LE-MONTHLY / BSD3A**: same related-party name-match rule and the same on-balance credit population; the ranking here is by counterparty/group over ALL non-exempt customers (Section 47), not the LE 10 % NOF threshold.

## 7. Framework asks

1. **BSD11 has no unit legend, but the catalogue's per-sheet unit hides mixed cells:** Sheet-6 mixes ¢ exposure amounts (C–F) with percentages (G–I) and is set to `percent` — its amounts export in cedis while Sheets 1/3/4/7/8 export in ¢'Million; Sheet-5 (`count`) mixes NO. and AMOUNT columns. The percentage / count lines already carry `unscaled=True`, so switching Sheet-6 (and Sheet-5) to `millions` in `catalog.py` would make the whole form consistent without touching this map.
2. **Sheet-3 row 9 is both the column-header row and the "1." item row** in the official file (labels captured on A9:H9), so only five detail rows (2.–6.) are addressable data cells; nothing to fix, recorded so nobody "adds" a row.
3. A `LineStatus` for **"register exhausted / not applicable"** (a rank row beyond the register, blank by design) would stop the completion sheet listing "director 4–6" as `input_required` for a bank with three directors. Today the engine maps `None` → `input_required`, which is safe (the bank confirms) but noisy.
4. `scripts/bog_coverage_matrix.py`: (a) `calc_pct` divides by the CAPTURED input count before the blank-grid adjustment on the next line (BSD11 shows "1840 % platform-fed" for 184 of 454 declared cells; BSD16/17 show 100 %) — compute it after `total_inputs += blank_grid_bound`; (b) `_test_files_for` does not recognise the multi-form test module `test_bsd10_11_16_17.py` for BSD11/16/17 (only the first code in a numeric list matches), so the matrix reads "framework gate only" although the module covers all four forms.
5. Bank-facing **register gaps** (not framework, but the data the map is ready for): director-interest (firm) register, staff-loan categories, relatives of directors/shareholders, property in satisfaction of debt, a facility ledger for half-year movements, and a full/part-time + "interests in other companies" field on the director record — each named in the corresponding row note.
