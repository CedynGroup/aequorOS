## What the form asks and where each figure comes from

FORM BSD15B (weekly, 9 days) is the bank's INTERNATIONAL banking tariff — one
sheet `International Banking Charges`, 21 numbered sections (letters of
credit imports / exports, SGS facility, documentary bills for collection,
clean bills, commitment fees, guarantees / bonds, exchange control, inward /
outward transfers, forex drafts, travellers' cheques, cheque lodgements,
account closure, returned cheques, COT, forex account maintenance,
statements). Item text sits in column A; the charge is entered in the first
value column `B` (the template's value columns carry number formats but no
header text).

**Data-gap closure (2026-08-16) — the tariff register is a Data Engine dataset.**
Every tariff cell reads the bank's `tariff_schedule` reference dataset
(`docs/data_engine/datasets/tariff_schedule.md`) through `refs.field {kind:
tariff_schedule, filters: {form: BSD15B, sheet: INTL, row_key}, field:
charge_value}` — `row_key` = `"<item>.<n>"` (`linemaps/bsd15a.tariff_row_keys`;
e.g. `1.1` = L/C imports establishment commission, `17.1` = account closure)
— and carries the row's `charge_value` text as published. Until the register
is ingested every cell resolves to `input_required` ("tariff register
required") at generation; once ingested all 309 are `mapped` (the Sample Bank
register — `tests/services/data_gaps/test_tariff_schedule.py`). Row selection
follows `linemaps/bsd15a.tariff_rows` (every labelled row except a heading
that introduces sub-lines; childless headings such as `17. ACCOUNT CLOSURE`
take the value). Sharp edge: `N/A` / `Nil` / `-` are null sentinels to the Data
Engine — spell out `Free` / `Not applicable`.
